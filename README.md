# 🎓 Student Result Management System

A GUI-based desktop application built using **Python Tkinter** and **OpenPyXL** to manage student academic records and export data into Microsoft Excel automatically.

---

## 🚀 Features

* **Add Student Details**: Enter student credentials along with marks for 5 subjects.
* **Automated Calculations**: Automatically calculates total marks, percentage, and overall status (Pass/Fail).
* **Excel Integration**: Auto-creates and updates `student_results.xlsx` as a local database.
* **Search Student Result**: Retrieve detailed performance cards using student Roll No.
* **Show All Results**: View all registered records in a clean tabular `Treeview`.

---

## 🛠️ Tech Stack

* **Language**: Python 3.x
* **GUI Framework**: Tkinter
* **Excel Handler**: OpenPyXL
